MS45 — Step 1: LAN Access

Status: Implemented; pending user verification on the Windows server and LAN client.
- Run.bat retains localhost mode by default; Run.bat --lan SERVER_IPV4 enables LAN mode on a selected private IPv4 address, TCP 8888.
- One-time firewall setup: from an elevated PowerShell, run .\Run.bat --firewall. Creates a persistent TCP 8888 inbound rule for Private/Domain profiles and LocalSubnet only; reuses matching rules and does not overwrite conflicting rules. Normal startup is unchanged. Windows execution pending user verification.
- Restrict Host headers to the bound address (local aliases in local mode); validate mutation origins, including LAN browser writes.
- LAN OPEN NX FILES uses the existing browser Workspace upload/open workflow; server-native file picker is disabled in LAN mode.
- Trusted LAN only: shared Workspace, no authentication or TLS yet. Restrict firewall access to trusted clients; no public exposure.
- NX conversion remains on the server and requires NX 2506; no NX installation required on browser clients.
- Preserve the verified MS44 visualization and section export features. README unchanged until user verification.
